# sydney-yogurt-lab

부산 광안리 셀프 토핑 프로즌요거트 매장 "시드니요거랩" 원페이지 랜딩과 대행 제안 초안.

| 파일 | 용도 |
|---|---|
| `index.html` | 랜딩 페이지. 한국어 본문 + 영어 요약, JSON-LD(IceCreamShop, FAQPage) 포함 |
| `llms.txt` | 생성 AI 크롤러용 사실 요약 |
| `robots.txt` | 크롤러 허용 정책(AI 크롤러 허용) |
| `sitemap.xml` | 사이트맵 |
| `PROPOSAL.md` | 3개월 실행안과 측정 지표 |
| `proposal.pptx` | 사장 대면용 제안서 |

## 배포 전
