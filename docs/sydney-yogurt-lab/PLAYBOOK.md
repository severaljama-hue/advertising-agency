## 2. 릴스 스크립트 5개
1. 담는 과정 (15초): 0~1s 기계에서 요거트 나오는 컷 / 1~5s 토핑 4종 올리기 / 5~8s 저울 숫자 올라감 / 8~12s 첫 스푼 / 12~15s 로고 + "광안역 5번 출구 7분". 자막: "내가 담는 만큼만 낸다". 캡션 첫 줄: "광안리 요거트 아이스크림, 직접 담는 셀프 토핑".
2. 광안역에서 오는 길 (20초): 5번 출구 → 골목 3컷 → 간판. 자막에 도보 시간. 고정 게시물.
3. 드롭 공개 (12초): 검은 화면 카운트 3,2,1 → 이번 주 조합 클로즈업 → "40인분 한정". 매주 목요일 12시 게시.
4. 두 컵 비교 (15초): 같은 무게 다른 조합 두 컵, "둘 다 4,500원대. 뭐 고를래?" 댓글 유도.
5. 대표 이야기 (30초): 대표가 카운터에서 "시드니에서 2년 동안 매일 이렇게 먹었어요. 한국엔 없길래 광안리에 열었습니다". 자막 필수.
