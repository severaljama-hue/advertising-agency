## 3. 실행안

### 1개월차: 원본 만들기
1. 도메인 sydneyyogurtlab.com 확보와 `docs/sydney-yogurt-lab/` 랜딩 배포. 가격(100g당 4,500원, 컵 1종), 오픈일(2026-05-29), 대표 이력(시드니 CJ 마케터 2023~2025)은 반영 완료.
2. 구글 서치콘솔·빙 웹마스터·네이버 서치어드바이저에 도메인 등록, 사이트맵 제출.
3. 네이버 플레이스·구글 비즈니스 프로필·인스타 바이오·블로그 프로필의 "웹사이트" 칸에 랜딩 URL 기입. 표기를 "시드니요거랩 (Sydney Yogurt Lab, 부산 광안리)"로 통일.
4. 트립어드바이저 무료 리스팅 신청 후 대표자 인증. 구글 프로필에 영어 소개문 추가.
5. 기준선 측정: 네이버 "광안리 요거트", "광안리 디저트", "광안리 아이스크림" 플레이스 순위 / ChatGPT·Perplexity에 "광안리 요거트 아이스크림 추천" 질의 결과 저장.

### 2개월차: 유입 만들기
1. 네이버 플레이스 광고(지역 키워드) 소액 시작. 클릭당 비용과 저장·길찾기 전환을 2주 단위로 기록.
2. 인스타·릴스 지역 광고: 광안리 반경 3km, 여행 관심사 타깃. 소재는 손님이 만든 컵 UGC.
3. 크리에이터 협업 3~5명(네이버 클립·릴스). 내돈내산 표기 준수. 목표는 블로그·클립에서 랜딩 URL로의 링크.
4. 인스타 운영 변경: 위치 태그 고정, UGC 리그램 주 2회, "이번 주 조합" 시리즈. 팔로잉 0 정책은 사장과 합의 후 부산 로컬 계정 팔로우 여부 결정.
5. 외국인 라인: 구글 리뷰 영어 요청 카드(QR) 매장 비치, 트립어드바이저 리뷰 유도.

### 3개월차: 측정과 조정
1. 14일 주기 재측정 표 갱신. 효과 없는 채널 예산 이동.
2. 랜딩에 FAQ 추가(실제 문의 기반), 시즌 토핑 페이지 추가 여부 검토.
3. 트립닷컴: 사업 개시 180일 경과 시점(12월 추정)에 액티비티 입점 문의. 그 전까지는 트립 모먼트 UGC 유도.

## 5. 하지 않는 것
- 리뷰 구매, 블로그 대량 체험단, 백링크 구매. 플레이스·도메인 제재 위험이 효과보다 크다.
- "순위 보장" 문구. 측정 없이 완료를 주장하지 않는다.
- 가시 텍스트와 다른 구조화 데이터. 랜딩의 JSON-LD는 화면 내용과 동일하게 유지한다.

## 6. 사장에게 확인할 것 (제안서 마지막 장과 동일)
1. 도메인 sydneyyogurtlab.com 구매 주체(매장 명의 권장)
2. 네이버 스마트플레이스·구글 프로필 관리자 권한 공유 방식
3. 월 광고 예산 상한(플레이스 광고 + 메타 광고 + 크리에이터 비용)
4. 팔로잉 0 정책 유지 여부
