# 시드니요거랩 브랜드·광고 전략 v2 (2026-09-06)

전제: 배달 진입 확정. 목표는 런던베이글뮤지엄형 "목적지 브랜드"(소수 직영 플래그십, 굿즈, 팝업, 대기 줄이 생기는 매장).

## 1. 런던베이글뮤지엄에서 가져올 것과 버릴 것
| 가져올 것 | 시드니요거랩 적용 |
|---|---|
| 공간 자체가 콘텐츠(런던 세계관) | "광안리의 시드니" 세계관. 서프보드·캥거루·코알라·본다이 비치. 매장 안 포토스팟 3곳 지정 |
| 희소성과 의식(한정 메뉴, 오픈런) | 월간 한정 토핑 드롭(수량 공개), 주말 한정 레시피, 1주년 한정 굿즈 |
| 굿즈 = 브랜드 자산 + 매출 | 컵·스티커·에코백·모자·토핑 키트. 굿즈 매출 비중을 지표로 관리 |
| 직영 소수 확장, 매장마다 다른 콘셉트 | 2호점은 데이터(브랜드 검색량 지역 분포, 배달 주문 지역)로 입지 결정 |
| 팝업으로 타지역 검증 | 부산 백화점 팝업 → 서울 팝업 → 2호점 |
| 버릴 것 | 20석에서 인위적 웨이팅 유도, 가맹 대량 확장, 가격 경쟁 |

배달과 희소성의 충돌 해결: 매장 = 셀프서브 체험(유일), 배달 = 완성형 시그니처 컵(야식). 두 상품을 분리해 매장 체험의 희소성을 지킨다.

## 2. 전략 기둥
1. 세계관: 네이비·크림·서프 비주얼 시스템, 레시피 이름은 시드니 지명(Bondi, Manly, Coogee), 대표의 시드니 2023–2025 이야기가 브랜드 오리진.
2. 의식: 무게 맞히기, 시요랩 픽 주간 드롭(브랜드 조합 + 한정 토핑, 수량 공개), 월간 토핑 드롭, 시즌 캠페인 "시드니의 여름을 광안리 겨울에"(시드니는 12~2월이 여름).
3. 콘텐츠 엔진: UGC(손님 컵) + 브랜드 채널(공간·레시피·사람) + 크리에이터. 애칭 "시요랩" 공식화.
4. 채널 확장 = 확장 검증: 배달(야식), 팝업, 온라인 굿즈·토핑 키트. 각 채널의 주문·방문 지역 데이터가 2호점 근거.
5. 측정: 브랜드 검색량, 웨이팅 발생 일수, 굿즈 매출 비중, 타지역 방문 비율, 배달 재주문율.

## 4. 액션 포인트 (담당 표기: 사장 / 대행)
### 9월 (지금)
- 사장: POS 4주치 공유, 카카오톡 채널 개설, 스마트플레이스·구글 권한 공유, 도메인 구매
- 대행: 기준선 리포트, 브랜드북 v1(컬러·타이포·톤·레시피 명명 규칙), 랜딩 게시·서치콘솔 등록, 릴스 12편 촬영, 플레이스 광고 시작, 시요랩 픽 주간 드롭 제작, 굿즈 1차 디자인(스티커·에코백), 불꽃축제 날짜 확인
### 10월
- 사장: 가을 토핑 3종, 불꽃축제 연장 영업·포장 사전 주문 준비, 배달 메뉴 시식
- 대행: 월간 토핑 드롭 1회차 예고·집행, 크리에이터 3~5명 방문, 축제 콘텐츠, 배달 패키지 디자인(컵·실링·스티커·동봉 카드), 배민 입점 준비
### 11월
- 사장: 배달 런칭(야식 시간대 18~22시, 반경 3km), 수능 이벤트
- 대행: "시드니의 여름" 캠페인 소재 제작(12월 시작), 배달 런칭 광고, 겨울 메뉴 콘텐츠, 백화점 팝업 제안서 발송
### 12월
- 대행: 시드니의 여름 캠페인 집행, 크리스마스 레시피, 대관 상품, 트립닷컴 입점 문의(180일 경과)
### 1~2월
- 대행: 저당 캠페인, 배달 재주문 쿠폰, 부산 백화점 팝업 집행, 발렌타인 커플 레시피, 봄 토핑 예고
### 3~5월
- 사장: 1주년 한정 레시피·굿즈 확정
- 대행: 1주년 캠페인, 2호점 입지 리포트(검색·배달·리뷰 지역 데이터), 서울 팝업 협의, 토핑 키트 스마트스토어 오픈
### 6~8월
- 대행: 외국인 콘텐츠(영·일), 호텔 제휴, 대기 관리 시스템(카카오 알림), 성수기 크리에이터 집중, 2호점 결정 보고
